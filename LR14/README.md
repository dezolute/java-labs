# Лабораторная работа № 14

Тема: файловый ввод и вывод в Java. Вариант 13 выбран по варианту в LR12 и существующему файлу `voleybol.txt` в начальном решении LR14.

Реализованы все пять заданий:

| № | Задание | Файлы в каталоге проекта |
|---|---|---|
| 1 | Запись сведений о волейболе, вывод свойств и чтение содержимого | `data/task1/voleybol.txt` |
| 2 | Ввод 10 целых чисел, запись, чтение и подсчёт кратных 3 | `data/task2/f.txt` |
| 3 | Генерация 20 целых чисел от −100 до 100; простые записываются в g, остальные в h | `data/task3/f.txt`, `g.txt`, `h.txt` |
| 4 | Ввод 10 расстояний в километрах, запись, чтение и среднее | `data/task4/f.txt` |
| 5 | Создание файла из 10 целых чисел, чтение и подсчёт кратных 4 | `data/task5/f.txt` |

Для каждого вычисления данные считываются из записанного файла. Задания используют отдельные папки, чтобы файлы `f` не перезаписывали друг друга. Повторное выполнение задания заменяет его результаты. Файлы сохраняются в UTF-8; ресурсы закрываются через `try-with-resources`.

Ноль и отрицательные кратные учитываются в заданиях 2 и 5. Простыми считаются положительные целые числа, большие 1, с двумя положительными делителями; отрицательные числа, 0 и 1 попадают в h. Порядок и повторы сохраняются. Расстояния допускают точку или запятую, должны быть конечными и неотрицательными. При ошибке ввода программа предлагает повторить значение, при завершении ввода прекращает работу с сообщением.

## Запуск

В IntelliJ IDEA откройте `pom.xml` и запустите `org.example.App`. Рабочая директория — корень LR14. Меню позволяет выполнить задание отдельно, все пять последовательно (пункт 6) или выйти (0).

В PowerShell из каталога LR14 при установленном JDK 9+:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -Mode Demo
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -Mode Examples
```

Скрипт компилирует исходники с совместимостью Java 8. `Demo` выполняет пять заданий с контрольными данными; `Examples` запускает четыре адаптированных примера из теории. Для байтового примера введите `Hello world!` и нажмите Enter.

При наличии Maven и его зависимостей:

```powershell
mvn test
java -cp target/classes org.example.App
java -cp target/classes org.example.App --demo
java -cp target/classes org.example.examples.TheoryExamples
```
