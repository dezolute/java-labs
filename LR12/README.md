# Лабораторная работа № 12

Вариант 13. В методичке два задания; пункты 1–30 внутри каждого задания — варианты.

- `org.example.task1` — задание 1 «Растения»: `Map<String, Plant>`, три дерева, три цветка и два кустарника, вывод ключей и значений циклом и итератором. Существующее решение перенесено в этот пакет.
- `org.example.task2` — задание 2 «Кафе»: удаление кафе со средней оценкой ниже 3, увеличение рейтинга на 1 при средней оценке от 4, печать кафе с заданным рейтингом, сортировка по убыванию средней оценки и по названию при равенстве оценок.

В каждом пакете есть свой `App` с методом `main`, который можно запустить из IntelliJ IDEA.
Средняя оценка кафе без отзывов считается равной 0. Рейтинг и средняя оценка посетителей — отдельные значения; повышение рейтинга не изменяет отзывы.

Сборка и тесты при наличии Maven: `mvn test`.

Запуск после компиляции:

```shell
java -cp target/classes org.example.task1.App
java -cp target/classes org.example.task2.App
```
